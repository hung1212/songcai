# 包号中文金额与平特一肖（v0.6.23）

## 每肖包号总额

`特包龙虎各二十一肖` 表示龙包20元、虎包20元，每个生肖分别把20元均分到该生肖的特码号码。2026马年：

|生肖|号码|每号金额|生肖总额|
|---|---|---:|---:|
|龙|03、15、27、39|5元|20元|
|虎|05、17、29、41|5元|20元|

总投注40元，与马年 `龙虎各5` 的号码分布、特码集合和赔付相同。中03等其中一个特码时，按每号5元赔付；以47倍含本赔率计算，返还235元。

即使没写元、米等单位，“二十”仍是每肖总额，“一肖”完整限定每肖包号。旧版通用金额拆分把“二十一肖”中的“一”误算进金额，提前拆断投注；本版把已识别的特包结构整体保留。金额高亮只标“二十”，玩法高亮完整标“一肖”；整理换行及粘贴不会把它们拆开，下一笔独立投注仍可正常分行。

本命生肖按5个号均分，其他生肖按4个号；不得固定每肖除以4。例如马年 `特包马龙各二十一肖` 为马每号4元、龙每号5元，共40元。多市场各自计费，重复列出的生肖按重复投注累计；不能精确均分到分、明确逐号计费冲突等仍提示核对。

普通后置“一肖”的特肖规则保留，不把所有特肖改为包号。

## 平特一肖是完整玩法名

`奥平特一肖狗五十` 等价于 `新澳 平特肖 狗 50元`：

- 奥：新澳市场。
- 平特一肖：平特肖；其中的一肖不能单独截取为特肖。
- 狗：一个生肖，投注总额50元，不展成狗的四个号码各50元。
- 依照所选市场的平特肖开奖范围和赔率赔付；当前默认看正码加特码，狗出现一个或多个号码都只赔一份。按非马2.05倍，中奖返还102.50元。

当前解析核心已支持此写法，本版将完整原句加入解析、界面、高亮、AI防误改及赔付回归验收，并补全AI规则说明。

两种写法都不改投注原文。解析与语义版本升级为20261015-1，旧版不适用的AI核验随之失效，已保存的历史赔付快照保持原样。
