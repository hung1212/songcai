# 二中二串号与拖尾 · v0.6.38

选号之间的“串”“拖”“对打”表示前侧号码分别搭配后侧号码，形成明确的跨侧组合。完整的“特串”仍为独立玩法，不替换为二中二。

## 生肖串号

`副号: 马串虎狗羊 二中二各50`

“副号”保留为原文署名。马年号码如下：

| 侧别 | 生肖 | 号码 |
| --- | --- | --- |
| 前侧 | 马 | 01、13、25、37、49 |
| 后侧 | 虎 | 05、17、29、41 |
| 后侧 | 狗 | 09、21、33、45 |
| 后侧 | 羊 | 12、24、36、48 |

前侧5个号码分别搭配后侧12个号码，共60组二中二，每组50元，总投注3000元。后侧生肖之间、同生肖内部均不新增配对，不合并为17个号码的普通复式。号码按账目业务日期的农历年展开，跨年后组数随实际号码数量变化。

仅明确二中二或继承二中二标题时应用；支持一个前侧生肖串多个不同后侧生肖。前后同生肖、重复后侧生肖、多前侧生肖、混合数字等未明确情况继续待处理。

## 固定号码拖尾

`副号: 新澳，二连4串5尾各10元`

这里“二连”配数字表示二中二。固定04，分别搭配5尾号码：

| 组合 | 单价 |
| --- | --- |
| 04＋05 | 10元 |
| 04＋15 | 10元 |
| 04＋25 | 10元 |
| 04＋35 | 10元 |
| 04＋45 | 10元 |

共5组，总50元。0尾只有10、20、30、40；固定号码属于所选尾数时排除与自身配对，例如05拖5尾为4组。固定号码须01–49，尾数须0–9。

## 尾数互拖

`副号: 3尾串5尾各10`

未另外写玩法，也按二中二处理。3尾03、13、23、33、43分别配5尾05、15、25、35、45，共25组，各10元，总250元。0尾串5尾为4×5＝20组。相同尾数互拖会产生重复组合，需要明确分组及份数，不自动猜测。

## 计账与赔付

- 三种连接词沿用同样的前后配对方式；已支持的号码互拖、单号拖生肖等也可使用这些连接词。
- 玩法前后置、明确标题继承、全角、中文金额及金额续行保持一致。空行、市场、玩家边界仍沿用既有规则。
- 每组两个号码都在六个正码中才中奖，特码不计入；使用账单对应的二中二赔率与退水配置。
- 详情显示两侧号码、实际组数、单价和组合。原文、高亮、行号及定位保留。
- AI须保留原分组和单价，不得改成普通复式、特串或连肖。缺金额、多个连接词、每号/每尾等计费冲突仍待处理。
- 标准规则R53、R54、R55；解析和语义版本20261021-2。旧错误解释失效重算，历史结算快照保留。
