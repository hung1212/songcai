# 投注账目保存与原文高亮 · v0.3.1

日期：2026-10-05。

## 打开新版

先按 ⌘Q 完全退出旧版，再打开 [Intel Mac 松财.app](../desktop-client/release/松财-0.3.1-mac-x64/松财.app)。新版使用独立目录，已有账目继续沿用同一应用数据目录。

## 账目保存、标题和切换

1. 在左侧“已保存账目”点击“＋”新建，然后输入或粘贴投注原文。
2. “账目标题”可以手工填写。留空时，按原文的第一个玩家名称自动命名；没有署名时使用“未署名玩家”中填写的姓名，仍没有则显示“未命名账目”。自动标题会跟随首位玩家名称更新，手工标题保持不变。
3. 原文、业务日期、玩家配置和标题自动保存；“保存到数据库”可以立即保存，不再弹出文件保存对话框。
4. 同名标题只保存一份，当前保存内容覆盖旧内容，不额外新增一份。标题会去除首尾空格；同名覆盖不区分日期，如需保留每天的账目，可使用“小明 10月5日”等不同标题。
5. 点击左侧名称切换账目，切换前先保存当前内容。关闭再打开会恢复上次查看的账目。

桌面版使用本地 SQLite 数据库 `ledger.sqlite`，原文按账目记录保存。首次打开新版会迁移旧 `draft.json`，原文件保留。旧版中存在同名文件时，迁移时加“迁移2”等后缀，保留历史原文；之后同名保存直接覆盖。“导出账单”仍可生成完整 JSON 备份，导入后同名标题同样覆盖。

“微信收件箱”保持独立：已确认记录和逐页原图不会因投注账目标题相同而被覆盖。浏览器开发预览仍使用浏览器本地存储，与桌面 SQLite 分开。

## 关键文字颜色

| 内容 | 颜色 | 示例 |
| --- | --- | --- |
| 玩法 | 紫色 | 特肖、特码、三中二、二连肖、复式 |
| 生肖／号码／分类 | 蓝色 | 牛、01、13、天肖、红波 |
| 金额 | 橙色 | 100、10.50、一百 |

例如“特肖牛 各100元”中，“特肖”为紫色，“牛”为蓝色，“100”为橙色。“各”“元”和玩家姓名保持普通文字，便于区分语义。

高亮直接显示在可编辑原文内，复制、修改、滚动仍使用普通文本。高亮不改变空格、号码、金额或解析结果，也不代表投注已经核对正确。超过20万字时暂用普通显示，保留编辑和保存功能。

## 放大编辑与按钮稳定性

点击“投注原文”右上角的“放大编辑”，输入区会放大到接近整个窗口。点击“收起编辑”或按 Esc 返回；原文、光标选区、滚动位置和三色高亮保留，继续自动保存。

修复了数据库保存回传触发重复保存与解析的问题。没有修改时不反复写入数据库，“解析文本 →”按钮文字保持稳定。

## 号码分布、生肖与排序

1. 在“号码分布”顶部查看49个号码的平均金额：当前筛选范围内的特码逐号金额合计 ÷ 49，未投注号码也计入分母。玩家、市场和当前/全部文本筛选均生效；特肖、连肖、连码等整项或组合投注不摊入逐号金额。
2. 高于平均的号码使用浅橙色底，在上方显示“超出 +金额”。例如平均100元、10号200元，显示“超出 +100.00”。平均和差额显示到分，先按未取整的均值判断；差额小于一分时显示“超出 <0.01”。
3. 每个号码上方显示生肖，下方显示波色和投注金额。生肖使用**当前账目业务日期**的农历年：2026-02-17起01/13/25/37/49为马，2027-02-06起切到羊；公历元旦不切换。
4. 合并跨农历年份的账目时，界面明确提示生肖标签和排序统一参考当前账目日期；各账目的解析和金额仍按各自原业务日期计算。
5. “排列方式”提供如下选择，所有方式均保留49个号码，排序不影响账目金额。

| 排列方式 | 用途与顺序 |
| --- | --- |
| 号码从小到大 | 默认01–49，快速找号 |
| 金额从高到低 | 金额最多的号码在前 |
| 金额从低到高 | 查看未投注和金额较少的号码 |
| 生肖顺序 | 鼠、牛、虎、兔、龙、蛇、马、羊、猴、鸡、狗、猪 |
| 波色顺序 | 红波、蓝波、绿波 |
| 尾数顺序 | 0尾到9尾 |

同金额、同生肖、同波色、同尾数时，均按号码从小到大排列。

## 同步修复的 OCR 空格问题

Mac 收件箱识别时结合图像字符坐标恢复数字分隔，保留最初 OCR 和每处补空格记录。已导入的旧图片可以用“用原图重新识别（新草稿）”重试；旧校正文字保留，新草稿需要重新核对，避免同一笔投注重复入账。

用户截图的 `23 1`、`42 1 23 41 2` 分隔已验证恢复。金额、一位数与重复号码有回归检查。小字玩法仍可能误识别，例如“三中二／三中三”，需对照原图核对。详情见[收件箱使用说明](微信收件箱第一版使用说明.md)。
