# 特码与平特肖集合最新开奖高亮 · v0.6.17

特码集合中的49个号码，按新澳、旧澳、香港各自最近已获取的一期开奖对照。进入页面先显示本地缓存，再自动更新开奖；也可点击“更新开奖”。顶部显示各市场特码球、日期、期号和核对状态。

- 对应市场确有投注且开出该特码，卡片显示浅红底、红框和“新澳 · 中”等市场标签。同号多市场命中时，分别显示标签。
- 悬停号码可看到对应市场、开奖日期／期号及该市场命中的投注金额。卡片原金额仍是当前筛选范围内的投入总额，不把其他市场的金额算作中奖。
- 单站或未确认的人工开奖显示虚线卡片、“待核对”标签；多网站冲突且未明确采用时不标记中奖。点击“查看／核对开奖”进入现有的最新开奖选择界面。
- 没投注的号码不标记，普通正码不套用特码标记。待处理及其他玩法不参与。
- 市场筛选、业务日期筛选、编辑或清空账目、空间切换后即时重新计算。业务日期只筛选投入范围，开奖始终采用各市场最新一期；不受全部统计当前查看的历史日期影响。
- 原有排序、生肖、波色、平均金额、超平均提示及点击查看来源保留。高亮仅是展示，不改写投注、赔率、赔付或历史结算快照。

来源选择继续复用现有规则：一致时按网站优先顺序选取，不同市场可以有不同开奖日期；新增冲突证据使旧确认失效。网络失败时保留已有开奖并展示其实际日期。

## 平特肖集合

十二生肖卡片采用相同的浅红底、红框及市场标签。顶部显示各市场最近一期的7个号码球、生肖、日期／期号和核对状态，并明确标注该市场“正码＋特码算中”或“仅正码算中”。

- 根据开奖日期的农历生肖表判断，跨农历新年自动切换，不能使用账目日期的旧生肖表。
- 遵守现有各市场平特肖赔付范围，默认正码和特码都算中，设置仅正码时排除特码。
- 同一生肖开出多个号码，只命中每份投注一次；原文多次购买同一肖仍按实际份数累加。
- 只标记对应市场确有投注的平特肖，特肖、连肖等玩法不参与。悬停可查看命中号码、市场及该市场命中的投注额，卡片大金额仍为投入总额。
- 多市场、核对状态、筛选、实时更新及空间隔离与特码集合一致。点击生肖继续查看来源、定位原文。

验证：核心检查覆盖两类玩法、跨市场误标、重复份数、农历切年、六／七码范围、与现有赔付计算的一致性、冲突及确认失效、历史日期独立、编辑和筛选。页面视觉检查使用模拟数据，与真实账目隔离。
