# 二中二号码互拖

适用版本：v0.6.36。

```text
新澳05-15-35-45拖19-39-25-13二中二各注5..
```

“拖”前后是两个号码列表，每组从两边各取一个号码，按二中二计费。上例为新澳市场，4 × 4＝16组，每组5元，总投注80元。

| 左边号码 | 与右边分别配对 |
| --- | --- |
| 05 | 05＋19、05＋39、05＋25、05＋13 |
| 15 | 15＋19、15＋39、15＋25、15＋13 |
| 35 | 35＋19、35＋39、35＋25、35＋13 |
| 45 | 45＋19、45＋39、45＋25、45＋13 |

短横线表示列举，不展开连续范围。两边内部不相互配对，不合并成8个号码任取二的28组，也不只按同位置配成4组。

玩法支持前置、后置或继承明确的二中二标题；支持常用号码分隔符、两侧括号、全角文字、中文金额，以及下一行单独写“各注5”。“各注／每注／各组／每组／各”均按每组金额处理。空行、市场和玩家边界遵循既有规则，下一笔不会继承本笔选号。

每个组合的两个号码都在六个正码内才中奖，特码不计入；赔付和退水使用账单对应的二中二配置。明细展示两边号码、组数、单价和全部组合，原文及行号保持不变。

号码只允许01–49。两侧号码相同时排除自身配对并显示说明；同侧重复、两边重叠造成同一组合重复、括号未配对、多个拖字、复式／胆拖混写或按每号计费时，仍须明确后处理。没有明确或可继承的二中二玩法时，不自动猜测玩法。

标准规则R52约束AI保留原分组和单价。解析及AI版本升级后，旧待处理或错误解释失效，原文按新规则重算；已保存的历史赔付快照保留。
