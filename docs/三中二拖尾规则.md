# 三中二双号拖尾 · v0.6.20

2026-10-14，标准规则 R40。

`新澳门三中二:11.33拖5尾，组10米。` 表示新澳三中二，固定11、33，分别搭配5尾的号码：

| 组 | 号码 | 金额 |
| --- | --- | --- |
| 1 | 11、33、05 | 10元 |
| 2 | 11、33、15 | 10元 |
| 3 | 11、33、25 | 10元 |
| 4 | 11、33、35 | 10元 |
| 5 | 11、33、45 | 10元 |

合计5组、50元。原文保留，明确分组直接计账，无需AI再次确认。

## 输入和范围

- 支持两个不同的01–49固定号码，拖一个0–9尾数。固定号可用点、逗号、顿号、空格或斜杠分隔，支持全角数字。
- “组10”“各10”“各组10”“每组10”均表示每组10元，金额支持中文和小数。紧接下一行的组金额可补全本笔，保留跨行定位。
- 0尾为10、20、30、40，不含00；其他尾数从01–49范围中展开，全年份固定。
- 固定号也在拖尾范围内时，排除该号码，避免一组出现重复号码。例：`三中二05.15拖5尾组10` 为05、15分别搭配25、35、45，共3组30元，详情说明排除05和15。
- 同一玩家的明确三中二标题可继承，后续普通投注不继承前面的固定号或尾数。市场、空行与玩家切换使用原有规则，多市场分别计费。

## 结算与展示

每组单独保存在账目里，不把七个号码合并成普通复式，不计算缺少原固定号的额外组合。每个已保存分组按其命中的正码数量结算：中2个正码用三中二的“中二正码”档，中3个正码用“中三正码”档；特码不作正码。两档金额均采用对应市场已设置的赔率。

例如正码为11、33、05、15、01、02，特码25，原五组中有2组中3正码、3组中2正码。若两档赔率分别为90和20（含本金），赔付为2×10×90＋3×10×20＝2400元。若只中一个固定号，但同一分组的尾号也中正码，该组仍按中二正码结算。

投注详情显示固定号码、尾数展开、实际组数、每组金额及所有分组；原文的玩法、尾数和金额继续分别高亮。
