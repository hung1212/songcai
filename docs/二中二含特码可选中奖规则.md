# 二中二含特码可选中奖规则

版本：v0.6.45。此规则只影响号码二中二的中奖计算，不改变原文解析、选号、组数或投注金额。

## 中奖条件

| 两个号码的开奖结果 | 默认关闭 | 开启后 |
| --- | --- | --- |
| 两个均在6个正码中 | 原二中二赔率 | 原二中二赔率 |
| 一个正码＋一个特码 | 不中奖 | 新设的独立赔率 |
| 只有一个特码，另一个号码未开出 | 不中奖 | 不中奖 |
| 其他情况 | 不中奖 | 不中奖 |

新档赔率留空，不预填或借用特串、二中特的赔率。开启时必须有有效赔率，否则不能保存。填写赔率本身不代表开启。赔率本金口径与该市场设置相同。

## 设置入口

统一设置：**开奖与赔付 → 赔率与来源设置 → 选择市场 → 二中二新增中奖方式**。开启后填写“二中二：一个正码＋特码”的赔率，再保存。新澳、旧澳、香港分别保存，各空间独立。

个别玩家：**玩家退水 → 选择账目名 → 玩家赔率 → 选择市场**。在“二中二：一个正码＋特码”一行选择：

- 跟随市场：市场开启就开启，市场关闭就关闭。
- 仅此玩家开启：即使市场关闭，该玩家也采用新档。
- 仅此玩家关闭：即使市场开启，该玩家仍只按两个正码中奖。

右侧赔率留空时继承市场该档赔率，也可填写自己的赔率。市场该档未填时，单独开启的玩家必须填写自己的赔率。切换玩家或市场保留未保存草稿；保存所有修改后生效。开关与独立赔率均按账目标题匹配，正文的发送人不改变设置归属。

## 计算示例

假设正码含01、02，特码49；投注“二中二01 02 49各10”，共三组，总投注30元。

仅为演示，假设原二中二赔率60，新档赔率20，均含本金：

- 01＋02：10 × 60＝600元。
- 01＋49、02＋49：2组 × 10 × 20＝400元。
- 开启时合计赔付1,000元；关闭时赔付600元。总投注一直为30元。

互拖只检查实际组成的跨侧配对；不会额外生成同侧组合。一组只进入一个中奖档，显式重复下注仍按原有份数计算。

## 展示与数据保留

本单中奖、全部账目统计及玩法统计采用相同规则。中奖明细标注“二正码”“正码＋特码”，结算截图把两档的中奖金额、赔率、赔付分别列出。原文中奖行高亮随结果更新。

退水仍归属二中二，按全部有效投注流水计算一次，不因新增中奖方式增加流水。特串与二中特继续使用各自的赔率和规则。

旧设置读取时补充默认关闭及空赔率；不自动开启。已保存的历史结算保留原金额及当时的设置，修改当前设置不会改写历史。并发修改同一开关会提示重新载入，不静默覆盖。

## 验证范围

覆盖默认关闭、旧设置兼容、只中一个特码不中奖、两个正码与新档分别赔付、复式与互拖、重复组、1–49完整号码池的独立组合枚举、含本／净赢赔率及分位舍入、玩家与市场覆盖、恢复继承、设置冲突、退水和截图、SQLite重启及历史保留、浏览器空间隔离。

原生界面检查在临时SQLite中操作，核对市场开关、缺价保存拦截、玩家三态选择、切换草稿、玩家独立赔率和两档截图；不操作用户实际账目。
