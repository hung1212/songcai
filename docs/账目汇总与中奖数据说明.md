# 账目汇总与中奖数据 · v0.4.7

## 清空全部账目内容

左侧“已保存账目”下方新增“清空全部内容”。点击后显示确认框，确认后一次清空所有账目的投注原文及对应 AI 解释记录；保留账目 ID、名称、排序、业务日期和未署名玩家绑定，金额和中奖明细随之归零。自动生成的标题会固定下来，空账目不会因同名而合并。新投注可以继续填写到这些账目中。

桌面端在同一笔 SQLite 事务中保存清空前备份并清空原文。只有全部操作成功才提交，写入失败则回滚。仅保留最近一次清空备份，重启后仍可点击“撤销上次清空”。清空后新增内容、改标题、调整排序或日期等操作会禁用撤销，避免覆盖新数据；仅切换账目不影响撤销。再次清空空账目不会覆盖备份。

清空范围仅为“投注账目”的当前内容；微信收件箱、开奖记录、赔率配置和已保存赔付历史继续保留。历史赔付中的原文快照仍能查阅，当前统计不会累加这些历史版本。

## 账目菜单的净输赢

每份账目名称下方，以及当前账目顶部和“中奖数据”中显示玩家净输赢：

**玩家净输赢 = 应付金额（按赔率计算，含退本金）− 投注总金额。**

- 正数显示红色“赢 +金额”；负数显示绿色“输 −金额”；相等显示“持平”。例如投注100元、应付4700元，玩家净赢4600元。
- 全部退本金时，净输赢为0，不误计为输钱。
- 缺开奖、缺中奖赔率、期号不一致或有待处理原文时，显示“待结算”，应付标为部分金额。
- 开奖来源或赔率未确认时，能计算的金额标为“试算”。空账目显示“空账目”。

菜单与顶部使用“全部账目统计”中选择的开奖范围，旁边标明最近已获取开奖或指定日期。“中奖数据”仍可独立选日期、查看已保存历史版本，并以该面板显示的开奖为准。

## 全部账目统计

左侧新增“全部账目统计”菜单，汇总所有账目的当前原文，包括不同业务日期的账目。逐账目结算后归集，不创建额外投注副本：

- 总投注金额、中奖账目数、中奖笔数／注数、应付合计、退本金及玩家净输赢合计。
- 新、旧、港各市场投注和应付，实际使用的开奖日期、期号及号码。
- 每份账目的投注、中奖笔数／注数、应付及净输赢，可点击返回原账目。
- 全部中奖明细，可按账目筛选；展开查看原文、赔率和赔付计算，点击“查看原文”定位。

默认使用本地最近已获取的开奖。点击“获取最新开奖”更新缓存，或指定开奖日期；多个来源一致时自动选第一个来源，冲突时展开“核对／选择开奖依据”处理。没有相应市场的投注时，该市场缺开奖不会阻塞其他账目的合计。应付表示计算金额，不代表已付款。

不同账目的原文生肖仍按各自业务日期展开。待处理投注不进入“已解析投注”合计；只要有账目未结算完成，净输赢合计就显示待结算，不把部分结果当最终结果。已保存赔付历史、微信收件箱记录不额外叠加到当前原文汇总中。

## 每个账目的中奖数据

打开“投注账目”，选择左侧账目，再切换右侧“中奖数据”。打开时采用各市场最近已获取的一期自动试算，支持选择开奖日期，只包含这份原文里的玩家和玩法；即使上方选了“全部文本”，本单中奖数据也不会合并其他账目。

- 显示本单投注、中奖笔数与注数、应付合计、退本金、待结算及原文问题数量。
- 新、旧、港分别采用各自最近已获取的一期，显示开奖日期、期号、正码、特码和来源；也可选择指定日期，缺期保持待结算。多网站一致时默认选列表第一来源，有差异时由用户采用。原文生肖选号仍按账目业务日期展开。
- 明细默认只看中奖，可切换全部投注、未中奖、待结算和退本金。展开后显示投注原文、行号、期号、注数及赔率计算。
- “获取开奖”复用已有多网站查询。“核对／选择开奖依据”显示各站结果；缺少交叉核对或有差异时，需要明确采用结果。赔率在“赔率／开奖设置”中按市场配置。
- 开奖依据和赔率均已确认、原文无阻塞问题、所有投注均完成结算后，勾选本单核对，再点击“保存本账目赔付”。

赔付记录在本地 SQLite 中保存账目 ID、业务日期、原文、开奖依据、赔率及计算结果。每个账目只列出自己的赔付历史，相同输入重复保存不新增；修改原文不会改写已保存版本。修改后刷新本单数据即可重新计算，旧版本仍可查阅。应付金额不代表已付款，软件不执行转账。

缺开奖、中奖档位缺赔率、期号不一致或仍有争议输入时保留待结算，不标成已结清。包含未完成项的合计标为“已算应付（未完成）”。

## 特码集合

左侧“特码集合”汇总所有已保存账目中已解析的逐号特码，可按业务日期、新／旧／港筛选。显示总额、每个市场金额、49号均值、超出均值部分、生肖、波色，以及号码／金额／生肖／波色／尾数排序。点击号码查看来源账目和该号码金额，点击来源行可回到原账目。

“天肖各100”“红波各100”等已展开到号码的投注计入；“特肖牛100”“红波100”、连肖、连码等独立玩法不混入逐号特码金额。汇总直接从账目计算，不生成副本，不会增加原账目的投注金额。跨日期时号码金额照各账目原日期展开，生肖标签按页面所示日期显示。

## 已保存账目拖动排序

按住左侧账目上下拖动，插入线表示放置位置；松开后自动保存顺序。拖动不切换当前账目、不改原文。也可聚焦账目后按 Alt＋上／下键移动。关闭再打开后保留 SQLite 中的顺序。

## 未署名玩家及无关文字

没有玩家署名的内容默认属于这份账目的同一位玩家，不再产生“未归属”警告。不同账目的默认玩家各自独立；明确写出的玩家名和市场继承规则保持有效。

普通称呼、客套话、表情等不影响投注解释的文字忽略解析并保留原文；玩法冲突、金额或号码不完整、取消或修改投注等有业务含义的文字仍需处理。例如：

```text
阿斯顿发新4.5.16.17.28.41各20米
阿道夫29.40各10米
```

解析为两笔新市场特码，120元＋20元＝140元，无玩家归属警告。

`特肖三中三1 2 100.` 同时指定不同玩法，提示明确玩法，暂不计入。
