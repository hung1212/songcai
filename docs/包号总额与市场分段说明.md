# 包号总额与市场分段 · v0.4.11

## 包单数总额

```text
新凹
包单数1100
```

“新凹”是新市场。“包单数1100”是01–49中全部25个单数特码合计1100元，每号44元，包含49号。号码分布、特码集合及赔付均使用每号44元；例如特码开49，按含本金47倍赔率应付2068元，不使用独立单双的49和局规则。

投注明细保留原文，并显示“每个市场总额1100元 ÷ 25个号码＝每号44元”。“包双数”同理按24个双数均分，例如包双数1200为每号50元。两边、三边沿用原约定：每个市场分别投注该总额。

支持冒号、空格、中文金额、全角数字及可精确均分的小数。例如“包单数：1100.25”为每号44.01元。为保持金额精确到分，不能精确均分时保留待处理，不暗中舍入或给某个号码多分金额。包单数／包双数与“各／每”并用、混入其他玩法或选号时仍须明确。

未带“包”的已有语义保持：单1100为独立单双玩法；单数各10是每个单数特码10元；红波100为独立波色，红波各100按号码计费。其他未确认的包法不自动套用此规则。

AI核验使用相同标准规则。包号候选返回原文总额，由本地程序展开号码和计算单价，拒绝无依据地改写原文金额。新版会重新解析旧账原文，历史赔付快照保留。

## 市场标题和分段合计

2026-10-09补充：v0.5.12明确市场标题只向后生效，带市场前缀的后续投注也可识别；真正的非合计尾注仅影响紧邻投注，不牵连之前多笔。详见[市场标题与尾注归属说明](市场标题与尾注归属说明.md)。

独立一行“新奥／香港／旧／两边”等，后接同一玩家投注时，作为新段落标题：

- 从标题开始切换后续投注的市场，不回改前段。
- 玩法重置为默认特码，避免把上一段末尾的三中三继承给新段号码。
- v0.6.15起，标题前的空行不影响新标题识别；标题后若出现空白行，下一组未写市场则默认新澳。下方旧示例的市场归属以[空行市场分组规则](空行市场分组规则.md)为准。
- “总金额”核对最近市场标题后的整段，包含该段不同玩法；“合计／总共”等仍核对整条消息。
- 换发送人后按既有规则重置市场。真正的尾部市场、明确市场矛盾或合计错误仍提示。
