# 二中二拖生肖规则

2026-10-10，标准规则 R30，客户端 v0.6.6。

## 用户确认的样例

原文：`二中二30拖鼠各10`

马年鼠肖为07、19、31、43。固定30与每个鼠肖号码各组成一组：

| 分组 | 金额 |
| --- | ---: |
| 30、07 | 10元 |
| 30、19 | 10元 |
| 30、31 | 10元 |
| 30、43 | 10元 |
| 合计 | 40元 |

玩法为二中二。“鼠”用于展开配对号码，不另记特肖投注，也不从五个号码任取两个生成十组。

## 解析与展示

- 单个01–49号码拖一个生肖，按每组金额计算。支持二中二、2中2、两中两，空格、冒号、全角和中文金额；玩法可从前文明确的二中二继承。
- 生肖号码按账目日期对应的农历年确定，春节当天切换；依据生肖实际四个或五个号码展开。
- 固定号若也在生肖号码中，排除自身配对，详情说明排除的号码并按有效组数计费。例如马年07拖鼠为（07 19）（07 31）（07 43），各10共30元。
- 市场及玩家沿用既有继承规则，多市场分别计费。后续普通二中二只继承玩法，不继承固定拖号。
- 详情显示固定号码、生肖展开号码、每组金额和全部配对；原文保持不变，保留高亮及定位。
- 无争议的本地解析直接计入，不要求AI确认。旧版核验解释按规则版本失效；AI候选必须保留拖号配对，不可改为普通复式或特肖。

## 中奖与赔付

逐个显式分组判断两个号码是否都在前六个正码中；第七个特码不参与二中二匹配。中奖金额为中奖组数乘每组金额，再按对应市场的二中二赔率计算赔付。

例如正码30、07、19、31、01、02，特码43：上述投注中3组，中奖投注30元；按当前默认60倍，赔付1800元。如果30仅为特码，则这4组均不中奖。

## 暂不自动推断的写法

多固定号码、多生肖、生肖互拖、其他玩法、复式／胆拖混写仍待处理，需明确列出分组。缺少金额、非法号码、按每肖或每号计费等冲突不会计入。当前规则不推断`二中二兔拖龙各48`的交叉组合方式。
