# 玩家退水与每日结算

v0.6.18起，统一在顶部“玩家退水”菜单设置，支持玩家默认值和各玩法单独设置。详见[独立菜单与玩法退水](玩家玩法退水设置.md)。以下为退水基础口径。

## 使用方式

在顶部“玩家退水”菜单按玩家填写“每10,000元流水退多少元”，点击“保存所有修改”。开奖赔付和中奖数据中保留跳转入口。支持搜索玩家和账目；玩家默认值留空或填0表示不退水；玩法值留空跟随默认，填0表示该玩法不退水。

例如填写100，等于退水率1%；有效流水15,000元，退水150元。按比例计算，不需要满一万元。最多填写两位小数，范围0至10,000元，界面同步显示百分比。

设置按当前空间保存到本地SQLite，重启保留。清空每天投注内容不会清除退水设置。新空间默认不退水，“只复制名单”不复制退水率。原文署名和绑定玩家沿用既有玩家身份；无署名账目使用账目ID，不会仅因标题相同而合并。改账目标题不改变未署名玩家的配置；更改绑定玩家或新建账目视为不同身份。

## 计算口径

- 有效流水：本次业务日期、已成功解析并完成中奖判断的投注。中奖和未中奖都计入，新澳、旧澳、香港按实际投注额各自累计。
- 待处理、缺开奖、期号不符、缺赔率等待结算项目暂不退水；开49和局退回本金的投注不计流水。未完成时只显示已算部分，不作为最终盈亏。
- 退水＝有效流水×退水率。每个账目内先按玩家汇总，再四舍五入到分；每日玩家退水累计这些账目金额，保证总额等于逐张截图之和。同一玩家跨市场的分位按余数分配，分市场合计与玩家合计一致。
- 应付＝原赔付（含应退本金）＋退水。
- 玩家净输赢＝应付－投注总额，正数为盈、负数为亏。这里只算账，不执行付款。

例如本单总投注15,000元、赔付20,000元、退水率1%，且全部正常结算：退水150元，应付20,150元，玩家盈5,150元。

## 展示与留存

每日玩家结算显示分市场应付、投注与有效流水、退水率、退水额和净输赢。单账目的中奖数据与结算截图单列退水；截图保留现有紧凑开奖区域，不增加账目名称。v0.6.19起，结算单与截图在退水合计下按玩法显示有效流水、费率和退水额，特码、平码、平特肖等分别列示。同玩法有多个退水档位时标记“多档退水率”；旧历史缺少玩法明细则显示未分类退水，不补算。

全部账目统计、顶部应付和净输赢、账目列表盈利排序包含退水。按玩法统计仍展示玩法本身的赔付与净输赢，并明确标注未含退水，避免把玩家退水重复分摊到玩法。

保存结算时保留当时的玩家退水配置、有效流水、退水额和应付金额；以后修改退水率只影响重新计算。旧历史结算缺少退水字段时按0显示，不补算或改写。退水率修改后旧预览失效，需要用新预览保存，防止用过时金额留档。

金额使用整数分与整数比例计算。新增测试覆盖比例、分位舍入、跨市场与账目汇总、未署名身份、待结算及退款排除、设置持久化、空间隔离、历史快照和截图。
