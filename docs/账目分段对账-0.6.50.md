# 账目分段对账 · 0.6.50

## 使用

在账目的「本单结果」打开「分段对账」。标签及原文底部会显示当前账目的段数。

以空白行分段：段内普通换行不拆段，连续空行只分隔一次，首尾空行不产生空段。支持含空格、全角空格、不换行空格的空白行。用户提供的三个「副号」消息形成3段；按马年号码表，投注依次为2640元、1160元、420元，共4220元。

每段显示原文起止行、各市场投注、已计投注、中奖投注、中奖号码／生肖／组合、注数和赔付。可展开原文、定位原文、复制本段或全部对账文本。每页10段，可筛选中奖或待结算段落。

## 口径

- 按整单已经完成的解析，依投注原始起始行归入段落，不重新解析每段，不改变市场继承、金额续行、AI解释或赔率。
- 中奖使用与本单当前中奖数据相同的开奖和玩家赔率。入口「选择／核对开奖」进入原有中奖数据页，支持最近开奖或指定日期。
- 赔付直接汇总整单结算条目，不再次按分段舍入；不包含玩家退水。和局退本金单独提示，已包含在赔付中。
- 待确认投注不计入「已计投注」。缺开奖、待结算、未确认赔率／开奖保留对应状态，不显示成确定未中奖。
- 历史赔付不标记当前原文；编辑尚未完成解析时暂时隐藏金额，完成后自动更新。
- 原解析如将投注跨空行合并，整笔只归起始段，并提示跨段，不重复分配或自行拆金额。
- 仅有说明文字的非空段仍保留，显示0元及说明段／待处理状态，方便按原文顺序对账。
- 对组合较多的中奖投注，每笔最多展示60个组合，最多检查3000个候选；不足以完整展示时明确提示。中奖注数、金额始终来自完整结算，不受展示上限影响。

## 验证

覆盖三段原文示例、连续空行、Windows换行、跨行金额、多市场、重复下注、待处理、缺开奖、历史／过期结果、跨段标记、玩家独立赔率以及组合玩法。界面验证包含分页、筛选、逐段定位、切换账目和编辑时隐藏旧金额。

通过本机数据库只读快照核对实际「副号」：各段投注与整单已计投注一致，各段赔付与整单赔付一致；没有修改用户原文、赔率、退水或结算记录。实际金额报告保存在本机忽略目录中。

## 0.6.51 · 简洁复制

- 「复制金额文字」仅复制 `段号:投注金额`，每段一行，例如 `1:10`、`2:30`。整数不带小数尾缀，非整数保留实际精度；「复制本段」采用同样格式。
- 「复制表格图片」生成段号／投注金额两列的简洁表格，可直接粘贴到微信。不包含名称、原文、开奖、中奖、赔付或合计。
- 复制全部涵盖当前账目的全部段落，不受筛选和分页影响。金额使用界面相同的已计投注，待处理未计金额不额外加入。
- 超过120段自动排列为多列，从左到右逐列阅读；单图最多480段，超过时明确提示使用文字复制全部，不截断段落。
- 原文正在解析时禁用复制；图片生成过程中如切换或编辑账目，取消该次过期图片复制。浏览器不支持图片剪贴板时会下载图片并提示；桌面使用原生图片剪贴板。
- 本次没有调整玩法解析、继承、金额计算或赔付规则。
