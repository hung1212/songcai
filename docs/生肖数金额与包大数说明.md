# 生肖数金额与包大数 · v0.4.13

## 同行不同单价

```text
新澳特：龙鸡羊兔马数10，猴鼠数各5
```

等价于：

```text
新澳特：龙鸡羊兔马数10，
猴鼠数各5
```

“数10”表示每个对应号码10元，可省略“各”。不能把10当作额外选号，也不能用后一笔的5元覆盖前一笔金额。

按2026马年：

| 投注 | 号码数 | 单价 | 金额 |
| --- | --- | --- | --- |
| 龙、鸡、羊、兔、马对应的特码号码 | 21 | 10元／号 | 210元 |
| 猴、鼠对应的特码号码 | 8 | 5元／号 | 40元 |
| 合计 | 两笔新市场特码 | | 250元 |

生肖仍按账目业务日期的农历年展开。只解析时保留原文；粘贴整段或点击“整理换行”时，在完整金额后的逗号、分号处自动换行，数字和标点不改写。原文高亮将10和5都标为金额，AI核验证据采用同一识别规则。

兼容“号码／数字”、中文及全角金额、两位小数。选号之间的逗号不单独拆笔。市场、玩家继承规则照常；换玩家默认新市场。逐号金额不能覆盖明确的特肖、连肖等相冲突玩法。

## 包大数每号金额

```text
新澳特包大数各五
```

这是25至49号（包含25、49）全部特码，每个号码5元，共25 × 5＝125元。“各五”是每号单价，不是整包总额，因此不均分5元。

号码分布、特码集合和赔付均使用每号5元。若特码开49，使用特码赔率，不套用独立大小玩法的49和局；以含本金47倍举例，应付235元。

支持“包大数各5”“包大数每号五元”等相同计费依据。仅写“包大数5”尚不能据此确定总额或单价，仍提示；“包单数1100”的既有总额均分规则保持。金额无效、明确玩法或计费冲突继续待处理。

新版自动重算旧账原文，并使旧规则版本的AI解释失效。历史赔付快照保留，已保存的历史赔付不会被自动改写。
