# 特串拖生肖 · v0.6.10

2026-10-11，标准规则 R34。

`特串45 拖 鸡各10，`表示固定45，与鸡肖的每个号码分别组成特串。马年鸡对应10、22、34、46，因此分成以下4组，每组10元，总投注40元：

| 组 | 号码 | 金额 |
| --- | --- | --- |
| 1 | 45、10 | 10元 |
| 2 | 45、22 | 10元 |
| 3 | 45、34 | 10元 |
| 4 | 45、46 | 10元 |

固定号码以投注原文为准：写`特串44拖鸡各10`则是44分别搭配10、22、34、46，同样4组40元。软件不会把45自动改为44。

- 生肖号码按账目业务日期所属的农历年展开，生肖可能有4或5个号码；固定号码属于该生肖时，排除与自身配对，详情说明排除号码与实际组数。
- 支持空格、冒号、全角数字、中文金额及金额单独续行。明确的独立“特串”标题可用于下一笔；后续普通投注不继承固定拖号。玩家和市场使用原有继承规则，多市场各自计费。
- 特串每组须一个正码加特码才中奖，固定号码与生肖号的位置可以互换。两者都为正码不算中奖，缺少固定号码也不算中奖。
- 使用空间内配置的特串赔率，默认150倍（含本金）。例如固定45为特码，正码出现10、22、34时中3组：中奖投注30元，默认赔付4500元；45为正码、10为特码时中1组，默认赔付1500元。
- 各组明确保存，不能把固定号码与生肖号码合并成普通复式，也不计算生肖号码内部的配对。
- v0.6.27起单个生肖拖另一个不同生肖按[特串生肖互拖规则](特串生肖互拖规则.md)交叉展开号码。多固定号、多生肖、多个生肖一侧的互拖、复式／胆拖混写，以及按每肖／每号收费等未明确写法保留待处理；非法号码和缺金额不计入。
- 结果详情显示固定号码、生肖展开及每组金额，原文、高亮及定位保留。AI核验保持原号码、玩法、金额和分组，旧版本错误解释自动失效，已保存赔付快照保留。
