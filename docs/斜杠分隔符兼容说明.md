# 斜杠分隔符兼容 · v0.4.12

投注字段、号码之间的 `/`、`\`、`\/` 及重复、全角形式视作分隔符。原文保留这些字符，只在解析时统一识别，不因无关符号要求用户确认或调用AI。

例如：

```text
新澳平特5尾60米，

老澳特\05+14+23+32+41各号6米

香港特：05+14+23+32+41各号5米
```

| 市场 | 解释 | 金额 |
| --- | --- | --- |
| 新 | 平特5尾，整项60元 | 60元 |
| 旧 | 特码05、14、23、32、41，每号6元 | 30元 |
| 港 | 特码05、14、23、32、41，每号5元 | 25元 |
| 合计 | 3笔，待处理0 | 115元 |

号码不会因为符号被忽略而拼接：`05\14`仍是05和14；重复下注按原有份数累计。连码的显式分组保持独立，不能合并成更大的复式。市场、玩法标题旁的分隔符和只有分隔符的行也兼容。

仅忽略不影响业务含义的符号。`各1/2米`的金额含义不明确，仍待处理；越界号码、缺失金额和玩法冲突继续提示。解析和AI标准规则同步升级，旧版本AI核验失败或待确认记录不会挡住当前规则已明确的原文；真实疑点仍保留。

回归覆盖截图原文、8种符号写法、原文与高亮保留、号码边界、重复份数、连码分组、市场继承、非法金额以及旧AI记录失效。

## 后置“一肖”表示特肖

用户确认“一肖”是特肖简称，允许放在金额后。例如 `奥特虎猪兔各十米一肖` 按虎、猪、兔每肖10元，共30元，不展开成12个号码。“奥”沿用既有市场规则：无前文默认新，有前文继承对应市场。

金额后的“一肖”留在所属投注中解析，不单独拆出；如果后面还有新的选号和金额，例如 `特虎各10米一肖牛各20米`，则“一肖牛各20米”是下一笔投注。`二肖中特`、`三肖中特`仍整项计费，`平特一肖`、连肖保留各自含义。“每号”或明确“特码”与“一肖”同时出现时仍保留冲突提示。
