# 二连肖拖肖 · v0.6.9

2026-10-10，用户确认，标准规则 R33。

`二连肖马拖（兔羊猪虎鸡）各20`拆成马兔、马羊、马猪、马虎、马鸡5组二连肖，每组20元，总投注100元。固定马必须出现在每组中，不能将六个生肖合并为十五组复式，也不展开号码。

- 支持单个固定生肖拖明确的生肖列表，括号可省略，列表可有空格、顿号等分隔。支持全半角括号、中文金额和单独金额续行。
- 前文明确声明二连肖时可继承玩法；普通后续二连肖不继承固定生肖。市场／玩家沿用现有规则，多市场分别计费。
- 组内两个生肖均在配置的开奖范围中出现，才中该组。默认连肖范围为七球；若配置为六个正码，则按该范围计算。
- 每组按是否包含农历当年生肖选择对应二连肖赔率。马年默认含马3.8倍，其他组4倍，可由空间赔率设置调整。五组全中时，默认赔付100×3.8＝380元；只中马兔和马羊时，中奖投注40元、赔付152元。
- v0.6.21按R41更新：重复被拖生肖保留对应组的实际份数，计费和中奖赔付均累加；三连肖双固定生肖拖法已支持。列表包含固定生肖、固定数量不符、复式／胆拖混写仍需明确分组；缺金额、括号损坏或每肖／每号计费冲突不计入。
- 结果详情显示固定生肖、被拖生肖、各组及金额。原文、高亮、行号和定位保留。
- AI只能保留拖肖或等价明确分组，不能改为普通复式。解析版本升级后，旧拖号错误和AI失败状态不再阻止已明确的投注计账；历史赔付快照保留。
