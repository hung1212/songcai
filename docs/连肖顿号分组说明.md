# 连肖顿号分组 · v0.6.8

2026-10-10，标准规则 R32。

`二连肖牛羊、羊猪、羊兔、牛兔各30`按牛羊、羊猪、羊兔、牛兔四个明确分组计费，每组30元，共120元。解析结果保存实际分组，并按这些组独立计算中奖；不得先去重成牛羊猪兔，再任取二生成六组。

- 顿号分开的多生肖片段，或顿号与逗号混用，按明确分组识别。适用于二连肖以及其他数量连肖，也支持明确连肖标题的继承。
- 每组必须包含玩法要求数量的不同生肖。组内缺项、超项或重复仍提示；跨组共享生肖正常，不提示重复。完整重复组按出现份数计费。
- 括号分组优先，括号间允许顿号，括号内顿号是组内选号分隔。
- `二连肖牛、羊、猪、兔各30`逐段均为单个生肖，保留普通复式含义：六组180元。非连肖玩法的顿号不触发本规则。
- 保留原文、行号、高亮及定位；详情展示全部原始组合、组数与每组金额。
- AI候选需保留原分组，不能用同一生肖集合的普通复式替代。旧版错误核验解释自动失效，已保存的历史赔付快照保留。

例如马年开奖包含牛、羊、猪而没有兔，原文只中牛羊、羊猪两组；没有投注的牛猪组合不能赔付。按普通二连肖4倍，每组30元，中奖投注60元、赔付240元。

验证：538项自动化测试通过，Intel Mac实际应用以隔离账目验证120元、4组每组30元、完整组列表及无错误提示。报告为 `desktop-client/reports/tests-0.6.8.log`、`desktop-client/reports/mac-startup-0.6.8.json`。
