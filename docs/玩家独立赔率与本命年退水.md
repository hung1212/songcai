# 玩家独立赔率与本命年退水 · v0.6.26

顶部“玩家退水／赔率”进入玩家设置，选中玩家后可切换“玩家退水”和“玩家赔率”。

## 玩家赔率

- 新澳、老澳、香港分别设置。留空继承该市场最新默认值，只保存实际填写的覆盖项；清空恢复继承。
- 普通赔率与本命年／含当年生肖赔率可分别覆盖。例如市场默认平特肖普通2.05、本命年1.8，可仅为小明设置本命年1.6；其他玩法和其他玩家继续用默认值。
- 支持现有全部赔付档位，包括三中二、二中特的不同中奖档。
- 本金口径、六／七码范围、和局和特殊生肖选择沿用市场设置。市场选择“随开奖日期的农历年切换”时，2026年春节起为马、2027年春节起为羊；固定马的旧配置仍按其配置执行。
- 赔率须大于0、不超过10000，最多四位小数。退水可填0关闭，赔率填0无效。

## 平特肖本命年退水

增加“平特肖（本命年）”，填写每万元有效流水退多少元。留空继承“平特肖”，其仍留空则继承玩家默认。填写0表示本命年平特肖不退水。

按所选开奖日期的农历年识别本命生肖；同一笔混合生肖按实际份数拆分流水，中奖和未中奖均计入，待结算不计入。例如马年“平特肖马鼠各100”，普通平特肖每万元退200，本命年退50，退水为鼠2元＋马0.5元＝2.5元。重复下注份数保留。

## 保存与结算

保存所有修改后影响当前单、全部账目、每日结算、净输赢和截图。玩家以稳定玩家ID识别，各空间独立。未署名账目的改名不改变玩家归属。

只合并实际修改过的字段，保留其他玩家或市场的并行修改；同一字段冲突时提示重新载入。历史赔付快照保留原设置、赔率和金额，不套用新设置改写。

测试覆盖市场/玩家隔离、默认值变更、清空覆盖、普通与本命年档、农历换年、混合生肖和重复份数、退水舍入、SQLite重启、浏览器空间、历史保护以及桌面界面保存。
