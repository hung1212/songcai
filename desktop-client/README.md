## 已实现的规则

- 默认新市场；两边为新、旧；三边为新、旧、港，各市场分别计费。
- 同一发送人、同一空行分组内的连续内容继承市场；新声明替换市场；遇到空白行或切换发送人重置为新。A → B → A 也重置，玩家汇总仍合并 A 的账目。
- 按业务日期的农历年展开生肖号码，使用 `lunar-javascript`。已验证 2026-02-17 切换马年、2027-02-06 切换羊年；公历元旦不换表。
- 特码、特肖、多肖中特、平特肖/尾/号码、连肖、二中二/三中三/三中二等连码、特串、1–10 不中。
- 二中特、2–4连尾、1–5粒平特任中（整组、明确复式、括号列组）；尾数保留0–9，不当作球号。
- 天地/阴阳/男女/吉凶/生肖颜色/笔画/四季方位分类按农历生肖表展开；五行固定，所有年份共用。分类明细保留原词、成员和号码。
- 独立波色/半波/大小单双及合单合双；`红波100`整项100元，`红波各100`为17个特码号码、共1700元。蓝/绿及半波、属性采用同类口径，待更多真实样例核对。
- 头尾与逐号集合展开；中文金额与两位小数；同行不同单价、部分跨行共享金额；显式分组与复式计数。
- `六肖中特虎牛兔马蛇龙100` 按一项 100 元计，不按六肖分别收取，也不作六连肖。
- 金额采用整数分；每笔保留原文、文件、起止行、生肖规则版本及每个市场的账目。解析账目与赔付快照分开保存。

侧栏新增“玩法赔率”“生肖分类”：前者将蛇年特殊赔率适用生肖改为马，提供输入与计费示例、搜索及原图；后者支持农历日期查表、分类展开号码、波色与固定五行。参考页用于查阅；实际赔付采用“开奖与赔付”中各市场保存的赔率配置，按原图预填特码47倍、含本金，未知分档留空。

示例：

```text
小明：旧 1 2 3 各100元
特肖虎100元
张三：特肖虎100元
```

结果为小明旧市场 400 元、张三新市场 100 元，总计 500 元。

## 开发与打包

需要 Node.js 22.19+（建议 Node.js 24）和 npm；收件箱使用内置 node:sqlite。

```sh
npm ci
npm run dev          # 浏览器开发预览
npm start            # 构建并启动 Electron
npm test             # 规则、数据库、OCR几何与桌面保存测试
npm run test:native-ocr # Mac本机Vision回归，需先构建native辅助程序
npm run audit:samples
npm run pack         # 当前平台程序目录
npm run dist:mac     # macOS arm64 / x64 DMG
npm run dist:win     # Windows x64 NSIS 安装包
```

安装依赖与首次打包需要下载 Electron 及打包工具。离线使用已安装的本机 Electron 构建 Mac 应用目录：

```sh
npm run build
npm run build:native # Mac上编译本机架构的窗口/OCR辅助程序，打包前执行
npm exec electron-builder -- --dir --config.electronDist=node_modules/electron/dist --config.mac.identity=null
node scripts/sign-preview.cjs release/mac/松财.app
npm run test:mac-app -- release/mac/松财.app
```

架构必须与本地 Electron 对应。正式分发需要另行配置图标、代码签名和 macOS 公证；当前只是本地试用包。

启动测试直接执行 `.app` 内的真实程序，使用临时账单和隐藏窗口，检查页面加载、渲染器初始化、首次绘制、实际页面标题、规则菜单、编辑器原文、500元测试汇总、CSS布局以及关闭保存；同时检查放大/收起、空闲1700毫秒没有额外数据库写入、号码均值/超额/生肖和排序。应在正常 macOS 桌面进程环境运行；受限命令沙箱可能阻止 Electron 连接系统窗口服务。赔付检查使用真实IPC和SQLite验证原文留存、分市场应付及重复保存；追加 `--draw-network-check` 可实测公开新澳门来源。测试报告写入 `reports/mac-startup.json`。

## 文件结构

## Mac 更新注意事项（v0.1.1）

2026-10-05定位“窗口显示压缩代码”的原因：旧版Mac关闭窗口后仍保留后台进程，在该进程运行时替换同一路径的应用文件，旧进程保留的ASAR文件索引会从新文件的错误位置读取HTML。按照旧索引读取新版文件，所得701字节与用户截图中的代码完全一致；文件本身未损坏，账单数据无需重置。

打开新版本前按 ⌘Q 完全退出旧版。此后使用检查运行状态的更新脚本解压，不覆盖仍在运行的程序：

```sh
npm run install:mac-preview -- release/松财-0.1.1-mac-x64.zip
```

脚本在解压前、替换前两次检查目标进程；检查失败或目标仍在运行会停止。已有应用目录会保留为更新前备份。该脚本应在正常Mac终端环境运行；不能把沙箱无法读取进程列表解释成应用已退出。后续更换同目录应用仍须先退出，不依赖签名验证或另起进程的启动测试来判断原进程状态。
